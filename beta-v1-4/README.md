# Las Casas del Reino — Beta V1.4: La Vigilia de los Cinco Fuegos

Nueva versión narrativa y visual para pruebas, separada de las ediciones V1.2 (raíz) y V1.3 (`/beta-v1-3/`).

Contiene 256 escenas, la Vigilia ramificada de las Cinco Casas, cinco brasas animadas en CSS, transiciones cinematográficas y recuerdos de las decisiones en la Reconquista y el epílogo.

**Guardado independiente**: `casas_reino_v14_beta_github`. Se permite exportar/importar progreso JSON a través del menú del juego. El progreso no migra automáticamente desde V1.3.

GitHub Pages sirve esta beta públicamente sin pago. La venta comercial no está activada y requerirá un sistema privado de entrega.
