# Las Casas del Reino — Beta V1.2

Aventura narrativa de fantasía biomecánica basada en el universo de **Las Casas del Reino**.

## Estado

- Código de la beta V1.2 incorporado en `main`.
- `index.html` actúa como cargador y reúne los 16 fragmentos de `parts/` en el navegador.
- Se conservan los recursos originales incluidos en el juego: narrativa, imágenes y música.
- Pendiente activar **GitHub Pages** para obtener el enlace público de testeo.

## Publicar gratis con GitHub Pages

1. Abrir **Settings → Pages** dentro del repositorio.
2. En **Build and deployment**, elegir **Deploy from a branch**.
3. Seleccionar la rama **main** y la carpeta **/(root)**; guardar.
4. Esperar a que GitHub muestre la URL pública y probarla desde un móvil.

GitHub Pages es gratuito para este repositorio público. El juego no requiere compras, suscripciones ni servidores de pago.

## Qué comprobar en el test

- Introducción del nombre del Vigía y uso en diálogos.
- Inicio y progresión de Casa Calcáneo.
- Continuidad de las decisiones, capítulos y desenlaces.
- Persistencia del progreso al cerrar y reabrir el navegador.
- Funcionamiento de música e imágenes en móvil y ordenador.

El progreso se guarda localmente en el navegador del jugador.
