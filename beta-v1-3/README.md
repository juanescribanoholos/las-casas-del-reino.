# LAS CASAS DEL REINO — V1.3 Beta

Esta carpeta contiene una beta narrativa de prueba, independiente de la beta pública V1.2 en la raíz. El motor, la música y la narrativa se cargan desde `parts/000.txt` hasta `parts/015.txt`.

**Las partidas no se mezclan:** la V1.3 utiliza `casas_reino_v13_beta_github`; la V1.2 conserva su clave original. Puedes exportar/importar progresos en JSON desde el juego.

**Sin cobros, ni acceso privado:** GitHub Pages publica recursos de este repositorio público. No es aún la edición comercial protegida.
